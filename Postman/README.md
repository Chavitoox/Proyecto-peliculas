En la carpeta Postman se guardaran las colecciones de postman para cada microservicio con los 3 datos de cada uno.

1. Para hacer eso metan cada pestaña de Get, Post, Put y delete en una colección de postman. <img width="705" height="144" alt="image" src="https://github.com/user-attachments/assets/3bc8154e-605d-417a-acc9-4d14c12d4195" />
2. En la colección denle al + para crear un request extra.  
<img width="233" height="142" alt="image" src="https://github.com/user-attachments/assets/ce224088-3380-4312-b985-cc651cd16f93" />  

3. En ese request vayan a Docs y pongan los 3 datos que obtuvieron del Get.
<img width="844" height="208" alt="Captura de pantalla 2026-05-24 172226" src="https://github.com/user-attachments/assets/2165517f-b4be-4edd-ab4a-d6f282263d61" />

4. Exportar esa colección para ello hay que: seleccionar los 3 puntos de la colección, luego darle a more y finalmente exportar.
<img width="224" height="68" alt="image" src="https://github.com/user-attachments/assets/1c9c420d-31ab-46db-b4dd-c2e114e3b3ec" />

6. subirlo al repositorio de Github Postman.

Si quieren comprobar si funciona la colección anteriormente exportada, en Postman denle a los 3 puntos arriba de donde dice collections, luego import y seleccionan el .json que quedo al exportar la colección.

**El paso 3 es para que todos tengamos los mismos datos en el mongoDB.  
Por lo que si quieren hacer un Post los datos para hacerlo estan en los .json de esta carpeta**
