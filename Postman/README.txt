En la carpeta Postman se guardaran las colecciones de postman para cada microservicio.

Paso 1: Para hacer eso metan cada pestaña de Get, Post, Put y delete en una colección de postman.
Paso 2: Exportar esa colección para ello hay que: seleccionar los 3 puntos de la colección, luego darle a more y finalmente exportar.
Paso 3: subirlo al repositorio de Github Postman

Si quieren comprobar si funciona la colección anteriormente exportada, en Postman denle a los 3 puntos arriba de donde dice collections, luego import y seleccionan el .json que quedo al exportar la colección.
